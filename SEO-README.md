# SEO Operating Rules

This repository is intentionally built for sustainable discovery.

## Do

- Write useful original documentation.
- Use descriptive titles.
- Link to the website when it helps the reader.
- Keep claims accurate.
- Update docs when product behavior changes.
- Maintain accessible content.
- Use real releases and real project activity.

## Do not

- Stuff keywords.
- Generate hundreds of thin pages.
- Create doorway pages.
- Buy ranking links.
- Spam comments/forums.
- Create automated backlink networks.
- Hide links or text.
- Copy competitor content.

Google's current Search spam policies explicitly address keyword stuffing, link spam, scaled content abuse, scraping and doorway abuse. This repository therefore treats usefulness and originality as the primary SEO strategy.
