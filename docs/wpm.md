# What Is WPM?

WPM means **words per minute** and is a common metric for keyboard typing speed.

A widely used standardized convention treats one word as five characters, including spaces. Under that convention:

`WPM = characters typed / 5 / minutes`

## Example

If a person types 250 characters in one minute:

`250 / 5 / 1 = 50 WPM`

Actual products may apply different rules for corrections, errors, pauses, or incomplete words. Always check the metric definition used by the specific typing test.

## WPM is not the whole picture

Two people with the same WPM can have very different accuracy and consistency. For practice, track:

- WPM
- Accuracy
- Error count
- Consistency
- Session duration
