# Online Typing Test

A typing test measures how quickly and accurately you can reproduce text with a keyboard.

## Useful metrics

### WPM

Words per minute is commonly calculated using a standardized five-character word. See [What is WPM?](wpm.md).

### Accuracy

Accuracy measures the proportion of typed characters that match the expected text.

### Raw vs net speed

Typing systems may distinguish raw speed from a corrected/net score. The exact metric definition should always be documented by the test provider.
