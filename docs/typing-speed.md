# Typing Speed, Accuracy and Consistency

Typing improvement is better measured as a combination of speed and correctness.

## Three useful dimensions

**Speed:** how quickly you produce the target text.

**Accuracy:** how often the typed characters match the target.

**Consistency:** how stable your performance remains through a session.

## A practical training loop

1. Start with a comfortable speed.
2. Prioritize accurate keystrokes.
3. Repeat short sessions.
4. Review recurring errors.
5. Increase speed gradually.
6. Re-test under the same conditions.

Avoid comparing results from tests that use different scoring rules as if they were identical.
