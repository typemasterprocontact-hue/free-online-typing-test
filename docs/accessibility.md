# Accessibility

Typing practice should be usable by people with different visual, motor and cognitive needs.

## Accessibility checklist

- Keyboard-accessible controls
- Visible focus states
- Sufficient text contrast
- Reduced-motion support where appropriate
- Clear error feedback
- Labels for interactive controls
- Mobile-friendly input
- Screen-reader-friendly semantics
- No essential information conveyed only by color

If you find an accessibility issue in TypeMaster Pro, please report a reproducible example through the repository issue tracker.
