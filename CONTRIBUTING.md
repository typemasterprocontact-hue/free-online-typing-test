# Contributing to TypeMaster Pro

Thank you for helping improve the project.

## Useful contributions

- Documentation corrections
- Typing education improvements
- Accessibility reports
- Language corrections
- Reproducible bug reports
- Developer tooling
- Tests and quality improvements

## Before opening an issue

Please check whether the issue already exists. Include:

- Page or feature
- Device/browser
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots when useful

## Content quality

Contributions should be original, useful and written for people first. Avoid keyword stuffing, copied articles, automated backlink placement, or pages whose primary purpose is search manipulation.

## Pull requests

Keep changes focused. Explain what changed and how you tested it.
