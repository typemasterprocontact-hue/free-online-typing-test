# GitHub → TypeMaster Pro Discovery Playbook

This repository is designed to earn legitimate discovery by being useful to developers, educators and typing enthusiasts.

## 1. Repository metadata

Use a concise description:

> Free online typing tests, WPM and accuracy practice, touch typing lessons, multilingual typing, and interactive typing games.

Suggested topics:

- typing
- typing-test
- typing-speed
- wpm
- typing-practice
- touch-typing
- typing-games
- keyboard
- multilingual-typing
- tamil-typing
- typing-tutor

Do not stuff every possible keyword into the repository.

## 2. README architecture

The README should explain the project before asking a reader to visit the website. Product links should be contextual and useful.

## 3. Documentation clusters

Create genuinely useful guides around:

- typing tests
- WPM
- accuracy
- touch typing
- games
- multilingual typing
- Tamil typing
- programming typing
- student practice
- exam practice
- accessibility

## 4. Legitimate discovery channels

- GitHub search
- GitHub topics
- GitHub releases
- Developer communities
- Relevant educational communities
- Open-source directories where the project actually fits
- Technical articles that genuinely reference the project
- User contributions and discussions

Do not buy links, automate forum comments, create fake accounts, or publish mass-generated pages.

## 5. Website ↔ repository relationship

The website can link to this repository from a real developer/open-source page.

The repository links to the website where an interactive demo is the appropriate next step.

## 6. Measurement

Track:

- GitHub repository views
- unique visitors
- referring sites
- popular paths
- Search Console impressions
- clicks
- queries
- landing pages
- branded vs non-branded queries

Never treat GitHub stars as equivalent to website traffic.

## 7. 90-day content cadence

Weeks 1–2:
- publish repository
- complete README
- add core docs
- add issue templates
- add security/accessibility guidance

Weeks 3–6:
- publish deeper typing guides
- improve game documentation
- document language support
- add screenshots and demos

Weeks 7–12:
- publish releases when real product changes occur
- contribute useful fixes/docs to relevant open-source projects
- build genuine community references
- review Search Console and GitHub referral data

The goal is durable discovery, not artificial link volume.
