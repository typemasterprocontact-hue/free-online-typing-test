# Internal Linking Matrix

## Cluster A — Typing tests

`typing-test` should connect to:
- WPM guide
- typing speed guide
- touch typing guide
- duration-specific tests

Duration pages should connect back to:
- main typing test
- WPM guide
- typing speed guide

## Cluster B — Games

`games` should connect to:
- typing games guide
- relevant category pages
- individual games

Each individual game should connect to:
- games hub
- one or two relevant learning resources
- typing test when a timed test is a logical next step

## Cluster C — Languages

Language directory should connect to:
- multilingual typing guide
- individual language pages

Each language page should connect to:
- main typing test
- language directory
- relevant lessons
- relevant games only when genuinely applicable

## Cluster D — Learning

Typing lessons should connect to:
- touch typing
- typing speed
- WPM
- typing test

## Cluster E — Exams

Exam hub should connect to:
- exam practice
- relevant language practice
- typing test
- official exam authority pages when discussing current requirements

## Cross-cluster principle

Links should follow user intent. A page about Tamil typing does not need links to unrelated game pages just for SEO.
