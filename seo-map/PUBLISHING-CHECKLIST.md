# Publishing Checklist

Before adding a TypeMaster Pro URL to GitHub documentation:

- [ ] URL verified live
- [ ] URL uses HTTPS
- [ ] URL is canonical
- [ ] Page is indexable
- [ ] Page has unique useful content
- [ ] Anchor text describes destination
- [ ] Link is contextually useful
- [ ] No tracking/query URL unless intentionally required
- [ ] No duplicate/redirect chain
- [ ] Claim on the GitHub page matches the current website

Before publishing a new `.md` page:

- [ ] It answers a real user question
- [ ] It is not a thin keyword variant
- [ ] It has original wording
- [ ] It contains only supportable product claims
- [ ] It links to the canonical website page
- [ ] It has related documentation links
