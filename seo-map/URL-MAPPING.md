## Anchor-text rules

Use descriptive anchors that match the destination. Rotate naturally between:
- online typing test
- typing speed test
- typing practice
- WPM practice
- touch typing
- typing games
- multilingual typing

Do not repeat an exact-match commercial keyword on every page.

## Canonical-link rule

Every website link in GitHub documentation should point directly to the canonical HTTPS URL. Do not link tracking parameters, alternate hostnames, duplicate query URLs, or redirected variants.
