# TypeMaster Pro Site Architecture

Known/high-value content families to map and maintain:

- Core: `/`
- Typing tests: `/typing-test` and duration routes
- Practice: `/learn/typing`
- Speed education: `/learn/how-to-type-faster`
- Games: `/games` and individual game routes
- Languages: `/typing-in/<language>`
- Exams: `/exams`
- Books: `/book`

The production site has a large route inventory. Maintain this document as a living map rather than hard-coding a guessed list of every URL.

## Important

The repository should not create fake doorway pages for every keyword. Each destination must have a distinct user purpose and useful content.
